# olist-ecommerce-analyticss
🛒 Olist E-Commerce Analytics

End-to-end data analysis on a real-world Brazilian e-commerce 
dataset to uncover sales trends, customer behaviour, and 
product performance insights.

📊 Dashboard
Built an executive-level Power BI dashboard covering:
- Revenue trends across 2016–2018
- Top product categories by revenue
- Payment method distribution
- State-wise order distribution across Brazil
- Delivery performance and customer satisfaction metrics

📈 Key Metrics
- 💰 Total Revenue: R$19.88M
- 📦 Total Orders: 115,000+
- ⭐ Avg Review Score: 4.08/5
- 🚚 Avg Delivery Time: 12 days

🔍 Key Insights
- Bed & Bath and Health & Beauty were top revenue drivers
- Credit card was the dominant payment method
- São Paulo had the highest order volume
- Consistent year-on-year revenue growth from 2016 to 2018

🛠️ Tools Used
- Python, Pandas, Matplotlib, Seaborn
- Power BI
- Jupyter Notebook

📁 Dataset
Olist Brazilian E-Commerce Dataset — 9 CSV files
Source: Kaggle
